# Request
本图为个人博客系统的宏观拓扑架构图，呈现逻辑为拓扑、构图范式为包容式（用浅色分区底板圈定各域，强调模块边界），配色科技蓝。系统分四个域：①桌面壳层：launcher.py（pywebview 桌面窗口）以随机端口启动 cms_core 后端并写入 backend_config.json 供前端端口发现，同时拉起 my-blog-manager 管理前端；②管理前端 my-blog-manager（Next.js 15）：settings 设置页、editor 编辑器、drafts 草稿、moments 说说、chatter 杂谈、music 音乐等页面，修改先进入 OperationContext 暂存队列，再经 backend_config.json 发现端口后以 HTTP 调用后端 REST API；③后端服务 cms_core（FastAPI）：config（站点配置解析与写盘备份）、drafts（文章发布）、sync（内容同步并过滤图床敏感行）、deploy（构建部署）、moments、music、picbed（图床上传）等路由模块，读写磁盘数据；④数据与部署层：siteConfig.ts、posts/moments/chatters Markdown、data 数据文件、public 静态资源，经同步链路复制到 XHBlogs 博客前端源码目录，next build 构建产出静态站点推送 gh-pages 分支，源码推 main 分支，最终发布到 GitHub Pages。
