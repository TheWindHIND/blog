### -不探求，真相无从显现-

<https://thewindhind.github.io/im-coming/>

灵感是刷 B 站来自一条评论，于是就做了。项目部署在 GitHub 静态页上。

最开始遇到的问题是静态页下的定位问题:

IPv6 地址库：国内 IPv6 部署时间短，很多地市的 IPv6 段被登记到省会或邻市。

移动网络：4G/5G 的出口 IP 经常在省内甚至跨省漂移，这是运营商的问题，无法解决。

中小城市：国外 IP 库（[ipwho.is](http://ipwho.is)）对三四线城市经常归到省会。(本项目对于部分国外IP可进行解析)

AI 给我的回答是:静态页无法实现强制 IPV4，这是受浏览器内核和操作系统决定的

我的解决方法:IP 归一化服务，通过服务代理获取纯净IPV4并请求定位服务 API

没什么好说的，总结就是:

**大模型只负责用于参考，真正的行动方向和实现方案由开发者主导。**

**在没有实现方向时，可采用多模型协作以找到灵感和实现方向。**
